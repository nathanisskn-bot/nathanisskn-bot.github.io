Privacy policy

Last updated: 2 October 2026

What the desktop setup accesses

With the account holder’s Google consent, the setup uses the Gmail read-only permission to list and download messages, including headers, bodies, and attachments. It also uses basic Google account identity information to confirm which Gmail account granted access.

How the data is used and stored

Messages are saved as individual .eml files on the account holder’s chosen local storage. The backup database, activity logs, and OAuth credentials are kept on that Windows computer. The files remain under the account holder’s control. The setup does not use Gmail data for advertising, profiling, or sale.

Sharing and security

The desktop backup obtains messages directly from Google and does not intentionally upload message content to this website or an operator-run server. Anyone with access to the computer or backup drive may be able to read the saved files, so the account holder should protect those devices and local credentials. The site itself is hosted by GitHub Pages, whose hosting practices are covered by the GitHub Privacy Statement.

Control and removal

The account holder may stop scheduled backups, delete local copies, and revoke this app’s Google access from their Google Account settings. Revoking access stops future downloads; it does not remove files already saved locally.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
