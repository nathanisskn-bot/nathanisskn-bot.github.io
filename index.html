Personal Gmail EML Backup

This is a private, account-holder-operated desktop setup for saving Gmail messages as individual .eml files on the account holder’s own Windows computer. It uses the open-source Got Your Back (GYB) backup tool.

The setup requests read-only Gmail access to download messages, including their headers, bodies, and attachments. It can check for new or missing messages on a schedule. It does not send, delete, label, or modify messages in Gmail.

This page explains the setup’s purpose and data handling. It is not a web-based email service, and no Gmail messages are displayed here.
